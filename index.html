Projects

Project: One Element Management System - OneEMS
Description:
As a part of the business, devices manufactured by various vendors were used. Each vendor has their own software installed to configure and manage the device. Volume of devices are in large quantity. Managing and maintenance of the devices with different manufacturer with unique software for each vendor becomes difficult. Aim of the project is to develop a single application which can be used to handle all the devices independent of the device manufacturer. Maintenance and handling of the device is easier, cost effective, easily manageable. Devices are used by cell site technicians, switch technicians, field assurance technicians, field assurance manager, regional engineer, systems assurance, systems assurance manager, administrator. Efficient and easy user interface is provided. Application programming interfaces (API) are used to communicate with other applications integrated operation portal, CARMS. Single sign on feature is implemented. Custom health checks, all health checks, preventive health checks can be performed on devices. Users can create their own list of devices. Add, edit, delete operation on the list can be performed. Map interface provides the user to view the devices on the other markets, regions. Search, sort, drag and drop functionalities are implemented. Configuration files can be copied into the devices as a batch. Remote configuration of the devices is possible. SSH session interface is provided to log into the device console.
